# Windows 1.0 Beta validation

Validation date: 2026-09-20.

## Physical PC

- Windows 11, build 26200, x64.
- AMD Ryzen 9 9950X, 16 cores; 93.6 GiB usable system RAM.
- NVIDIA GeForce RTX 5070 Ti, approximately 16 GB VRAM; driver 610.88.
- PyTorch/torchaudio 2.7.1+cu128. A real CUDA tensor operation passed.
- The user installed and ran the preview on this PC and confirmed that the app works.

## Real transcription

The self-authored 12-second melody generated by make_audio.py was used. No recordings or raw local logs are published.

| Check | Result |
| --- | --- |
| Large, Automatic, CUDA | Passed; actual model parameters on cuda:0 |
| Large, explicit CPU, offline | Passed; actual model parameters on cpu |
| Complete source processing | Three of three chunks on both runs |
| MIDI content | 20 note-on events; 11.23 seconds of MIDI |
| Custom folder with spaces and café | Passed |
| Existing-file collision | Original preserved; distinct complete MIDI written |
| Offline CPU network attempts | Zero socket.connect / socket.getaddrinfo events |

The offline test used HF_HUB_OFFLINE and a Python audit hook that rejects socket connection and DNS attempts. The PC's network adapter was not disabled. Both tested runs produced identical MIDI bytes for this sample. Timing and note accuracy on other recordings will vary.

Optional tempo detection now skips uncached beat weights rather than initiating a download during transcription. Note timing remains unquantized.

## Automated checks and fixes

- 23 worker tests and 9 interface tests pass locally.
- Fixed private Python setup failing on Windows minor-version junctions by pinning the patch version and selecting its real directory.
- Fixed dependency installation with spaces in the engine path.
- Fixed Try Again after incomplete dependency setup and stale installing status after failures.
- Reworked the desktop layout, contrast, spacing, setup controls, and MuScriptor Local heading.
- The release build workflow tests the packaged executable, installer, and a fresh CPU engine under Windows PowerShell in a path containing spaces. The final successful run is linked in the release notes.

## Explicit limits

Small and Medium end-to-end transcription, offline CUDA in a separate run, other NVIDIA cards, Windows 10, drag/drop and cancellation in every final UI state, and the complete manual upgrade/uninstall preservation cycle remain unvalidated. CPU fallback classification is unit-tested; no physical GPU failure was induced. The executable is unsigned.

The owner requested publication after confirming the app works. These limits are retained in the beta notes rather than represented as completed tests. The macOS release and tag v1.0.0-beta.2 are unchanged.
